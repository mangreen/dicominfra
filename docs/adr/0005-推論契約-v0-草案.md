# ADR 0005：推論契約 v0.1 為通用假契約

- 狀態：提議中（待 DS 團隊審閱）
- 範圍：本服務與內部推論平台之間的請求與結果格式

## 背景

影像模態與模型輸出尚未定義，但流程需要先有明確的契約才能實作與測試。

## 決定

先採用通用假契約（見 `docs/contracts/inference-v0/`）：

- `request_id` 為冪等鍵，同一個 ID 重送必須得到同一個結果。
- 測量值為十進位字串，單位使用 UCUM，避免浮點誤差。
- `succeeded` 一定有 `measurements` 且沒有 `error`；`failed` 則相反。
- `error.retryable` 由平台明確指出。
- 契約中不出現病患資訊；輸入只傳已去識別化的物件參照與 SHA-256。

## 後果

- 真實 DS 模型的輸出可能與此不同，接上後契約需要提高版本並調整；這是已知的簡化。
- schema 以 JSON Schema 儲存並由測試守住，修改契約需要同步更新範例與測試。
- 未決問題清單見契約目錄的 README。
